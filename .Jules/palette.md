## 2026-10-19 - Found several icon-only buttons missing aria labels\n**Learning:** Found several icon-only buttons representing UI actions (like close modal, hide/show password, close toast) lacking `aria-label` attributes and properly hidden SVGs in various modals and toast components. This pattern impacts screen reader usability across the application.\n**Action:** Add `aria-label` explaining the action to all icon-only `<button>`s, and set `aria-hidden="true"` on their child SVG icons.
