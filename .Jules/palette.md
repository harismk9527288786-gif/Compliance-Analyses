## 2026-09-12 - Accessibility: Accessible Names on Icon Buttons and Inputs\n**Learning:** Auditing the UI revealed that several icon-only buttons (like password toggles and modal close buttons) and search/filter inputs lacked an accessible name, making them unreadable for screen readers. Using `aria-label` effectively fixes this without altering the visual design, but care must be taken not to apply redundant `aria-label` attributes to elements that already have visible text, `sr-only` text, or a `title`.\n**Action:** Add `aria-label` directly to standalone `<input>` elements and icon-only `<button>`s, while appending `aria-hidden="true"` to their child SVGs.
